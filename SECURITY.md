# Sicherheitsrichtlinie

## Unterstützte Versionen

| Version | Sicherheitsupdates |
| --- | --- |
| `1.9.x` | Ja |
| `< 1.9.0` | Nein |

Bitte zuerst auf die aktuelle Version aktualisieren, bevor ein Problem gemeldet wird.

## Sicherheitsprobleme melden

Bitte keine öffentlich sichtbaren Issues für Sicherheitslücken verwenden. Nutze
stattdessen die private Kontaktmöglichkeit des Maintainers oder GitHub
Security Advisories im Repository.

Eine Meldung sollte enthalten:

- betroffene Version und Windows-Version
- reproduzierbare Schritte
- erwartetes und tatsächliches Verhalten
- mögliche Auswirkungen
- relevante Logs ohne persönliche Daten

## Responsible Disclosure

Wir bestätigen den Eingang möglichst zeitnah, prüfen die Auswirkung und stimmen
einen Veröffentlichungszeitpunkt mit der meldenden Person ab. Bitte gib
Betroffenen angemessene Zeit für ein Update, bevor Details öffentlich gemacht
werden. Keine Tests gegen fremde Systeme oder Daten durchführen.
