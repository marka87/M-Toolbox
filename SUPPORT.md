# Support

## GitHub Issues

Nutze [Issues](https://github.com/marka87/M-Toolbox/issues) für reproduzierbare
Fehler. Verwende die Vorlagen und füge Version, Windows-Version und Schritte
zur Reproduktion hinzu.

## Feature Requests

Neue Ideen bitte als Feature Request mit Problemstellung, gewünschtem Nutzen
und optionalem Lösungsvorschlag einreichen.

## Bug Reports

Vor dem Melden:

1. Aktuelle Version installieren.
2. Problem mit möglichst wenigen Schritten reproduzieren.
3. Persönliche Daten und Zugangsdaten aus Logs entfernen.
4. Prüfen, ob bereits ein Issue existiert.

## Diskussionen

Allgemeine Fragen, Designideen und Nutzungshinweise gehören in GitHub
Discussions, sobald diese im Repository aktiviert sind.

## FAQ

**Welche Windows-Version wird unterstützt?** Windows 11 x64.

**Benötigt jede Funktion Administratorrechte?** Nein. Nur bestimmte Reparatur-,
Treiber- und Systemaktionen fordern erhöhte Rechte an.

**Warum ist Winget erforderlich?** Das Software Center nutzt den Windows
Package Manager für Suche, Installation, Deinstallation und Updates.
